# 首页方块阵背景动效规范

> 版本 v1.0 · 2026-10-23 · 状态：已实现
> 实现：`src/components/BlockField.astro` + `src/styles/global.css`（`.home-hero` / `.block-field`）
> 参考图：`attachments/image.png`（788 × 788，间距约 23px、圆点约 3px，浅紫点阵；本方案按反馈改为方形块阵）
> 交互预览：`design/dot-matrix-preview.html`（含明暗主题与青/紫两套强调色切换）

---

## 1. 设计意图

把参考图的等距网格转译成方形块阵，再变成一层「会被指针唤醒的表面」：

- 平时完全不显示，页面保持干净的暖纸底；方块阵只在指针靠近时局部显形，不参与叙事，不与文字竞争。
- 指针经过时，以光标为圆心的一小片区域**方形块垂直向上浮起**并染上强调色，像一张绷紧的薄膜被轻轻托起。
- 方块离开影响区后平滑落回原位，没有回弹、没有拖尾、没有持续自转。

关键词：**等距、方形块、抬升、局部高亮、安静**。动效只回答「指针在这里」，不做视觉表演。

与站点既有语言的关系：延续 `#FEFDFA` 暖纸底、青碧强调色与「克制动效」原则；参考图的紫色只作为备选色相，不改变站点主色。

---

## 2. 范围与层级

| 项 | 决策 |
| --- | --- |
| 覆盖范围 | 仅首页首屏（Hero 区域），从视口顶部到 Hero 下缘再延伸约 120px，最大高度 880px |
| 不覆盖 | Experience & Projects、Recent Notes、Footer；避免整页噪点与无效绘制 |
| 定位 | 相对页面内容绝对定位，随内容一起滚动；不做 `position: fixed` 视差 |
| 层叠顺序 | 页面底色 → Canvas 交互层 → 正文内容 → 导航 → 颗粒纹理 |
| 命中 | 整层 `pointer-events: none`，不拦截任何链接、文字选择与滚动 |
| 语义 | 纯装饰，Canvas `aria-hidden="true"`，不进入焦点顺序 |

边缘处理：通过椭圆遮罩从中心向四周淡出，显形区在左右与底部没有矩形硬边；顶部可以完整保留，让方块可以从导航后方出现。

## 3. 几何与密度

| 参数 | 桌面 ≥ 960px | 过渡 761–959px | 移动 ≤ 760px |
| --- | --- | --- | --- |
| 方块间距 `--field-gap` | 24px | 22px | —（不启用） |
| 方块基准边长 `--field-size` | 3px | 3px | —（不启用） |
| 峰值方块边长 | 5.4px（×1.8） | 5.4px | —（不启用） |
| 影响半径 `--field-influence` | 150px | 130px | — |
| 最大抬升 `--field-lift` | 9px | 8px | — |
| 方块阵原点 | 左上角，整数像素对齐 | 同左 | —（不启用） |

参考图约为 23px 间距 / 3px 圆点。这里保留参考图的密度，改为 **24px 间距 + 3px 基准方块**：方块阵只在指针附近显形，显形时以 3px 方块铺开，高亮边长放大到 5.4px，形成清晰的「块抬起」效果。

方块不设圆角、不做尺寸抖动；基准方块以整数像素对齐，保证边缘清晰，高亮放大时允许亚像素过渡以保持连续。显形后呈现规整的方块矩阵，而不是散点噪声。

## 4. 颜色

颜色全部走 CSS 变量，Canvas 初始化与主题切换时读取，不在 JS 里写死色值。方块阵默认完全透明；指针进入后，整片方块阵先以低透明度显影，光标附近再提升到峰值。这样静止时不露出网格，悬停时又保留背景矩阵的完整感。

### 4.1 浅色主题（默认）

| 用途 | 值 | 说明 |
| --- | --- | --- |
| 页面底色 | `#FEFDFA` | 既有 `--bg` |
| 悬停底纹 | `rgb(27 25 22 / 0.07)` | 悬停时整片显现，静止时透明 |
| 峰值方块 | `rgb(23 168 184 / 0.92)` | 站点 `--accent` 的 RGB 通道 |
| 柔光 | `rgb(23 168 184 / 0.22)` | 仅 `influence > 0.35` 时叠加，模糊半径 8px |
| 遮罩 | 中心实、边缘透明 | 见第 2 节 |

### 4.2 深色主题

| 用途 | 值 |
| --- | --- |
| 悬停底纹 | `rgb(243 237 227 / 0.09)` |
| 峰值方块 | `rgb(79 203 216 / 0.92)`（`--accent-ink` 的 RGB 通道） |
| 柔光 | `rgb(79 203 216 / 0.26)` |

深色主题只改变底纹、高亮色与柔光；静止时同样不绘制任何方块。

### 4.3 强调色相

默认使用站点青碧色。若希望完全复刻参考图的紫色，只需覆盖这三个变量：

```css
--field-peak-rgb: 139 123 240;
--field-glow-rgb: 139 123 240;
--field-peak-a: 0.92;
```

预览页提供「青碧 / 参考紫」切换，便于直接比较，不作为正式站点配置。

## 5. 交互模型

### 5.1 状态

| 状态 | 触发 | 表现 |
| --- | --- | --- |
| 静止 | 指针不在首屏 / 页面加载 | 不绘制任何方块，页面保持纯底色，无 rAF |
| 进入 | 指针进入方块阵的空白区域 | 160ms 内能量从 0 升到 1，整片底纹淡入，影响区内的方块同时抬升；名称、简介、标签、导航与下方文本区域不触发，指针落在这些内容上时背景淡出 |
| 跟随 | 指针移动 | 影响区以 60ms 时间常数平滑跟随，方块向上抬升并高亮 |
| 驻留 | 指针停止 | 影响区停在指针处，保持抬升；渲染循环在 120ms 后自动休眠 |
| 离开 | 指针移出首屏或窗口 | 380ms 内方块淡出并落回，画布恢复全透明，之后完全停止绘制 |

### 5.2 影响场

对每个方块，设其中心到平滑后指针的距离为 `d`，影响半径为 `R`：

```text
t = clamp(1 - d / R, 0, 1)
falloff = t² × (3 - 2t)          // smoothstep，边缘无硬切
influence = falloff × energy
```

- 抬升：`y = -9px × influence`，只做垂直位移，不做水平推移或旋转。
- 边长：`size = 3px × (1 + 0.8 × influence)`。
- 底纹：`alphaBase = baseAlpha × energy`，只随整体显影能量变化，不跟随光标形状。
- 高亮：`alpha = peakAlpha × influence`，方块从透明连续过渡到青碧，不出现中间脏色。
- 柔光：`influence > 0.35` 时叠加，随影响值线性增强，避免整片雾状发光。
- 方块只出现在抬升后的位置，原位不保留底块，视觉上是一块从纸面浮起。

### 5.3 指针平滑

- 指针位置用指数平滑跟随：`k = 1 - exp(-dt / 60ms)`，避免高刷新率下手感发飘或迟滞。
- 能量进入用 160ms、离开用 380ms 的不对称时长：出现要跟手，退出要从容。
- 触屏、`hover: none`、`prefers-reduced-motion: reduce` 一律不启用跟随。

### 5.4 不做的事

- 不做点击爆发、波纹扩散、粒子拖尾。
- 不做无人交互时的自动呼吸或漂移动画；静止就是静止。
- 不做鼠标速度驱动的形变或倾角。

这些效果会提高注意力成本，与「背景」定位冲突。若后续需要，作为独立开关再加。

## 6. 响应式与降级

| 场景 | 行为 |
| --- | --- |
| 桌面（精细指针 + hover） | 完整交互 |
| 平板 / 触屏 | 不显示方块阵（无 hover 不触发），页面保持干净；不启动 Canvas 渲染循环 |
| `prefers-reduced-motion: reduce` | 不显示方块阵，不注册指针监听，不启动 rAF |
| 无 JavaScript | 不显示方块阵，页面内容完整（纯装饰，不影响阅读） |
| Canvas 初始化失败 | 不显示方块阵，不出现空白框或报错 |
| 页面不可见（切标签页） | 取消 rAF，回到页面时按当前指针状态恢复 |
| 窗口缩放 | `ResizeObserver` 在下一帧重建画布与网格参数 |

Canvas 默认透明；只有能量大于 0 时才绘制方块。因为没有常驻底图，首次悬停不需要交叉淡入，也不会出现图层错位。无 JS、触屏与减少动态效果下看不到方块阵，是预期的留白，不是缺失。

## 7. 性能约束

| 项 | 预算 |
| --- | --- |
| 新增 JS（minify + gzip） | ≤ 3KB（实测 2.7KB），无第三方依赖 |
| Canvas 数量 | 1 个 |
| DPR 上限 | 2（Retina 下不按 3 倍渲染） |
| 每帧绘制 | 清空画布 1 次 + 底图 `drawImage` 1 次 + 影响区内约 80–140 个方块 |
| 静止时 | 0 个 rAF、0 次绘制、0 次布局读取 |
| 首屏 CLS | 0（Canvas 绝对定位，不占文档流） |
| 目标帧率 | 1440 × 900、M 系列 Mac 上 ≥ 55fps |
| Lighthouse | 性能不低于改动前基线（≥ 95） |

实现要点：离屏 Canvas 预绘悬停底纹，按 `energy × baseAlpha` 整体淡入；交互帧再绘制影响区内的抬升方块；主题切换时重建底图并重绘一帧；滚动与缩放不触发逐帧计算。

## 8. 可访问性

- 动效不承载信息，关闭后不影响任何功能与内容理解。
- 不产生闪烁：无周期性明暗变化，交互频率由用户控制。
- 不改变文字对比度：方块阵始终位于文字下层，峰值方块边长 5.4px、间距 24px，不形成大面积色块。
- 静止时画布完全透明；`prefers-reduced-motion` 下不显示方块阵，与纯背景一致。
- 键盘用户不会遇到焦点陷阱或额外的 Tab 停靠点。

## 9. 验收标准

1. 静息状态：页面无可见方块，保持纯底色；Canvas 像素全透明，无残留。
2. 悬停状态：整片底纹先淡入到 0.07 / 0.09 的透明度；光标处 150px 半径内方块继续增强并连续抬升，最大位移 9px，中心接近青碧实色，边缘平滑衰减。
3. 指针移动时无抖动、无跳帧、无明显的「追赶」迟滞；停止移动后 120ms 内渲染循环休眠。
4. 指针离开首屏后 500ms 内方块全部淡出消失，画布恢复全透明，之后无任何绘制。
5. 浅色 / 深色主题切换后 1 帧内颜色正确，无闪白或残留旧色。
6. 390px 触屏宽度：无 Canvas 动画、无方块显示、无横向溢出。
7. 系统开启「减少动态效果」：不显示方块阵，与纯背景一致，控制台无报错。
8. 禁用 JavaScript：不显示方块阵，页面内容与布局完整。
9. 首屏内容、导航与链接的点击区域不受影响；文字选择正常。
10. `pnpm check` 与 `pnpm build` 通过，新增 JS 体积在预算内。

## 10. 参数总表

```css
.block-field {
  --field-gap: 24px;              /* 方块间距 */
  --field-size: 3px;              /* 方块基准边长 */
  --field-lift: 9px;              /* 最大向上位移 */
  --field-influence: 150px;       /* 影响半径 */

  /* 悬停底纹（整体淡入）与高亮（局部） */
  --field-base-rgb: 27 25 22;
  --field-base-a: 0.07;
  --field-peak-rgb: 23 168 184;
  --field-peak-a: 0.92;
  --field-glow-rgb: 23 168 184;
  --field-glow-a: 0.22;
}
```

实现层高由 `.home-hero` 决定：`.block-field` 使用 `height: calc(100% + 120px)` 且 `max-height: 880px`，因此背景止于 Hero 下缘约 120px 处，由椭圆遮罩淡出。交互预览 `design/dot-matrix-preview.html` 使用同一组数值，变量前缀为 `--dot-*`，仅作离线对照，不参与构建。

| 变量 | 作用 | 调整影响 |
| --- | --- | --- |
| `--field-gap` | 网格密度 | 变小更密、更接近参考图，但更抢注意力 |
| `--field-size` | 方块基准边长 | 大于 4px 时会盖过文字肌理；小于 2px 时又会读成圆点 |
| `--field-lift` | 抬升幅度 | 小于 6px 不明显，大于 12px 会像故障抖动 |
| `--field-influence` | 高亮范围 | 与抬升幅度共同决定「波峰」宽度 |
| `--field-base-a` | 悬停底纹透明度 | 0 时整片底纹完全不显影，只剩光标附近的局部方块 |
| `--field-peak-rgb` / `--field-peak-a` | 高亮色与强度 | 必须与站点强调色一致，除非刻意做第二强调色 |

| 运行时参数 | 值 | 说明 |
| --- | --- | --- |
| 指针跟随时间常数 | 60ms | 指数平滑，高刷新率下保持同样手感 |
| 能量进入时长 | 160ms | 指针进入时底纹与局部方块逐渐显形 |
| 能量离开时长 | 380ms | 指针离开后淡出并回落 |
| 休眠阈值 | 120ms + 能量归零 | 静止后停止 rAF |

## 11. 实现与验收记录

已按本规范接入首页，保持 Hero 结构与联系入口不变：

- 组件：`src/components/BlockField.astro`（Canvas 与指针交互，DPR 上限 2，静止休眠）
- 触发门控：只有指针位于空白区域时才唤醒背景；`.profile-name`、`.profile-bio`（含标签）、`.teaser`、`.recent` 与 `.nav` 内的指针事件会让背景淡出，不启动动效。
- 样式：`src/styles/global.css` 的 `.home-hero` 与 `.block-field` 段
- 页面：`src/pages/index.astro` 在 `.home-hero` 中挂载背景层，内容层保持在其上方

已确认项：默认青碧色相；范围仅首屏（Hero + 120px，最大 880px）；触屏保持静态、不显示方块阵。

本地验收（1440 × 900、DPR 2，Chrome）：静息画布 0 个非透明像素；悬停底纹淡入且峰值像素为 `23 168 184 / 234`；高亮方块顶部相对 24px 网格上移约 10px（3px 方块 + 9px 抬升的合成偏移）；指针离开后 700ms 内回到 0 像素；暗色主题峰值为 `79 203 216`；`prefers-reduced-motion` 与 390px 触屏均为 `display: none`、0 像素；820px 宽度下间距为 22px；页面无横向溢出。`pnpm check` 0 error，`pnpm build` 通过。
